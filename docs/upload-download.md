# 资源上传与下载

资源文件与元数据词条分别管理。你可以只补充词条，也可以在有权提供文件且账号允许上传时，把原始文件绑定到对应条目。

## 上传前

1. 确认你有权上传和提供该文件。
2. 查找或补齐对应作品、表达或发行的词条，核对版本。
3. 保持原始文件与原始质量，填写能说明内容和用途的文件名。
4. 准备必要的来源，格式建议见[资源收录与投稿标准](/contribute-guide)。

## 上传与绑定

使用界面提供的上传入口。客户端会计算文件指纹，已有相同内容时复用文件，避免重复存储；大文件可以分片上传。

上传完成后，按实际用途绑定到正确词条，例如原档、音轨、光盘镜像或扫描资料。文件已经存在不代表它已经绑定到你的目标，完成后请回到词条核对资源入口。

上传与绑定需要登录及相应权限。开发者的初始化、上传、完成和绑定协议见[存储上传与下载](/api-storage)。

## 下载与可见性

上传者与具有存储审核权限的人可以直接读取文件。其他人只要能看到至少一个绑定词条，就可以读取；公开词条绑定的文件支持匿名访问。不可见文件会显示为不可用。

通过页面提供的资源入口下载。临时下载地址有有效期，失效后重新获取即可；长期引用图片或文件时应使用稳定的内容入口。

## 原始文件的使用

平台提供原始文件，不生成转码后的预览流。音频、视频、图书等内容请交给合适的播放器或阅读器打开。文件与条目版本不符时，先核实来源，再纠正绑定或资料。
