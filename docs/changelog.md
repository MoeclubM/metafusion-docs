# 更新日志

## 2026-09-16 — 站点内容与政策页按实现校正

逐条把首页、核心理念、服务条款、隐私、版权、联系、FAQ 与更新日志里的可核实断言拿去核代码、路由、迁移与线上响应，收掉无出处或已过时的说法：

- **域名口径**：适用范围由 `metafusion.io` 改为实际部署域 `findverse.cc`（服务条款页）；
- **注册要求**：用户名与密码为必填（用户名 2–80 字符、密码 12–72 位），邮箱选填，留空时按「用户名@站点域名」生成占位地址（账号服务 `Register`）；
- **限流**：补齐实际的三层——账号服务认证写入类接口 15 次/分钟、目录服务按路由 120 / 60 / 10 次每分钟分档、网关按前缀 30 r/s 与 5 r/s；`/api/storage/` 由「不限流」改为实际的 30 r/s（burst 100）；并说明只有目录服务的路由级限流带 `Retry-After`；
- **邀请链**：隐私政策里的 `invited_by` 改为实际的 `auth.invites` + `auth.invite_uses` 两表；
- **账号权利**：设置页当前只提供资料查看与改密码，资料更正与账号注销需联系站务（不写自助入口）；
- **版权页**：删掉「下载入口展示版权与合规提示」这一未实现的说法；`robots.txt` 由「禁止直链索引」改为实际的「允许抓取公开页面，靠鉴权与限流保护资源」；
- **实体骨架名称**：理念页的八类改与 `definitions.kinds` 一致（主体 / 集合 / 作品 / 内容单元 / 内容表达 / 发行版本 / 载体 / 收录位置）；
- **公告板块**：由「不开放日常发帖」改为引导口径（该板块当前未做发帖限制，编目与合规问题请走 `bug_report`）。

## 2026-09-16 — 文档按实现校正

概览、快速上手、FAQ、社区指南与首页文案按代码实现重新核对，收掉一批从未落地的能力表述：

- **认证**：不再出现个人访问令牌（`mfp_` 前缀）与 `X-API-Key`；程序化接入统一以会话令牌（`mf_session` Cookie 或 `Authorization: Bearer`，访问令牌 15 分钟 + 服务端会话 24 小时）与 OAuth 2.0 授权码为准；
- **检索**：统一为 `GET /api/catalog/entities` 的 `q`（标题与译文的子串匹配），不再宣称 MusicBrainz 兼容 API 层、独立检索端点、罗马音匹配、即时联想或分词与相关度排序；分页为 `limit` / `offset`；
- **限流**：改为实际口径——账号服务对认证写入类接口按 IP 15 次/分钟，目录服务按 IP + 路由做路由级限流（120 / 60 / 10 次每分钟分档），网关按前缀限流（`/api/` 与 `/api/catalog/` 30 r/s、burst 50，`/api/auth/` 与 `/api/setup` 5 r/s、burst 10，`/api/storage/` 30 r/s、burst 100）；超限 `429`，目录服务的路由级限流带 `Retry-After`；不再声称按登录状态区分的全站配额或 `X-RateLimit-*` 响应头；
- **互动服务**：板块按服务端实际播种的六类（站点公告、闲聊杂谈、求助答疑、考据评注、反馈与建议、评论专用）描述，删除不存在的私聊功能与未实现的发帖频控承诺；
- **资源**：下载受绑定实体可见性约束、只分发原始文件（不做转码与在线播放），与本页 2026-08 早期的记录一致；
- **权限**：能力表按权限码对齐（实例设置、权限组与用户、邀请码、OAuth 客户端、类型与关系定义、货架与外部库规则、编目审核与合并）。
