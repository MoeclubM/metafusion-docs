# 更新日志

## 2026-10-03 — 媒体编目与编辑流程

- 发行版本、CD/BD/黑胶、小说章节与动画分集按八实体骨架记录，独立歌曲和录音可以跨发行复用。表达组合、显式版本组与单条收录编辑见[元数据目录核心架构](/catalog)。
- 整个条目编辑器按基本信息、归属与收录、附加信息、图片与标识、关系、说明与来源分区，切换保留同一份草稿。
- 模板自动选择采用显式条件和优先级，不按已填字段猜类别；字段、词表、关系约束与受支持展示区块可通过 definitions 管理。说明见[IFLA LRM 增强版实体模型](/frbr-model)。
- 对比页修复缓存恢复时选中状态循环，单个已选条目加载真实题名与封面。
- 精简重复的历史接口说明，检索匹配范围统一参考[全文检索](/api-search)；升级、迁移与恢复流程在代码仓开发文档维护。

## 2026-10 — 检索与服务入口

- OpenSearch 作为可选关键词候选索引，PostgreSQL 负责最终过滤、可见性和回读；索引不可用时回退数据库，见[全文检索](/api-search)。
- 规范实体详情入口为 `/catalog/{id}`，顶栏提供统一搜索入口，目录首页为 `/home`。
- 账号、互动与存储通过同域网关聚合；接口归属和认证方式见[API 概览](/api-overview)与[认证与凭证](/api-auth)。

## 2026-09-23 — 公开实体资源读取

公开实体绑定的原始文件可匿名读取；上传与绑定仍需登录，资源访问以实体可见性和资源状态判定。接口与限制见[存储上传与下载](/api-storage)。

## 2026-09-19 — 站内通知

上线收件箱、未读角标、已读操作与事件聚合，通知只对收件人可见。当前保留期不自动删除业务通知，评论回帖成功不依赖通知投递成功。

## 2026-09-18 — PAT 与目录限流头

账号服务支持个人访问令牌，权限取签发者当前拥有的权限码；目录路由限流返回额度与重试响应头。现行认证、吊销时效和限流范围见[认证与凭证](/api-auth)。

## 2026-08-21 — 独立文档站

上线模型、共建规范、API 与站务说明，以及正文检索和移动端导航。文档站内容以本仓库为源；开发实现与部署契约在 [MetaFusion](https://github.com/MoeclubM/MetaFusion) 主仓维护。
