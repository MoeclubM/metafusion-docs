## 2. 账户与邀请

- 注册需提供用户名与密码（用户名 2–80 字符，密码 12–72 位）；邮箱为选填，填写时请保证真实有效——留空时系统会按「用户名@站点域名」生成占位地址。
- 邀请码（如要求）用于风控与溯源，滥用邀请链（批量注册、女巫）将被封禁。
- 是否开放注册、是否要求邀请码由**实例设置**决定（`registration_enabled` / `invite_required`，管理台 `PUT /api/admin/settings`）。

- 你对自己提交的元数据、文本、媒体文件负全责，保证拥有必要权利或属于合理使用/公共领域。
- 提交即授予 MetaFusion 在站内展示、索引、备份与格式校验的非独占许可（平台不做转码）。
- 禁止：侵权内容、未授权的大规模抓取、垃圾信息、恶意脚本、规避鉴权与限流。

## 4. 元数据开放与媒体受控

- 元数据（`work` / `release` / `agent` 等实体）默认开放可被索引与通过 API 复用，遵循本条款与站内署名要求。
