# 资源收录与投稿标准

投稿可以是一条有来源的词条，也可以是你有权提供的原始文件。建立元数据不要求同时上传资源。

## 投稿步骤

1. **先查重**：用原名、译名和编号检查现有作品与发行版。
2. **确认层级**：分辨你要补充的是作品、具体内容、发行版还是参与者；参考[元数据目录教程](/catalog)。
3. **填写资料**：从「新建条目」或已有条目的编辑入口，填写能核实的信息。
4. **补充依据**：附来源与具体修改说明，不确定的资料留空。
5. **保存与核对**：按权限保存草稿、提交审核或发布，回到详情页检查结果。
6. **上传文件（可选）**：确认权利与版本后，按[资源上传与下载](/upload-download)完成上传和绑定。

## 来源与文件要求

词条采用可核验资料，优先官方网站、制作或发行方资料、实物与出版物。来源应说明它支持哪些事实。不同来源冲突时说明分歧，不猜填。

文件保持原始质量和内容，避免为了符合推荐格式而重复转码。以下格式仅供选择工具时参考：

| 内容 | 常见格式 |
| --- | --- |
| 无损音频 | FLAC、ALAC、WAV |
| 有损音频 | MP3、AAC |
| 视频 | MP4、MKV |
| 图书与漫画 | EPUB、PDF、CBZ、CBR |
| 封面图片 | JPG、PNG、WebP |

封面保持原始比例，优先清晰且有权使用的图片。来源官方不自动意味着允许转载；权利不明时留空。

## 草稿、待审与发布

草稿用于保存尚未完成的资料，待审条目等待审核。两者只对创建者与具有相应管理权限的人可见。已发布条目公开展示，至少需要一条语言资料。

审核意见会指出需要补充的来源或修正的结构。按意见修改后再提交。已发布内容需要下架、合并或停用时，由具有生命周期管理权限的成员处理。

每次修改都保留修订记录。命名、重复合并和争议处理见[词条编辑与合并规范](/editing-guide)。
