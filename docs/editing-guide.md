# 词条编辑与合并规范

编辑的目标是让资料更准确、更容易核对。你可以先修正一个译名、补一条来源或完善一项参与关系，不必一次补齐整条发行链。

## 提交前的四步

1. **检查现有词条**：搜索原名、译名和外部编号，确认没有重复。
2. **核对来源**：优先官方资料、实物与出版物，确认来源支持你要填的具体事实。
3. **选择层级**：作品记录创作身份，录音与译本记录具体内容，编号与包装记录在发行层。
4. **说明改动**：填写本次改了什么、依据是什么，并添加至少一条来源。

无法核实的信息留空。来源有冲突时写明分歧，避免把推测作为事实提交。

## 名称与多语言

采用来源支持的正式名称，在相应语言中补充译名与常用别名。正式题名里的季数、卷号或「剧场版」若用于识别作品，应保留；附加的载体、编码或压制信息放到对应层级。

个人与团体优先采用公开使用的名称。同一个主体的不同艺名可记录为别名，通过参与关系连接作品，避免为每部作品重建人物。

## 不同事实放在哪里

| 资料 | 合适的位置 |
| --- | --- |
| 作品身份、简介与主题标签 | 作品 |
| 同一作品的章节或篇目 | 内容单元 |
| 录音、译本、正片剪辑 | 表达 |
| 品番、条码、发行日期与包装 | 发行版 |
| 分盘、分卷与承载格式 | 载体 |
| 曲序、页码或时间定位 | 收录位置 |
| 作者、演唱者或角色身份 | 主体，通过关系参与作品 |

更多例子见[元数据目录教程](/catalog)。同一份录音或正文被多次发行时复用已有表达。

## 图片与外部编号

使用清晰、未拉伸且有权引用的图片，标明来源；外部地址失效时及时更新。临时下载地址不适合长期作为封面。

外部编号应核对所属层级和原始格式。可用的外部数据库以编辑界面为准；登记了某个数据库并不代表已经支持自动导入。

## 疑似重复与合并

先比较来源、创作者、编号、所属层级和实际内容，确认是同一实体后再提出合并。不同表达或发行版通常应各自保留。

合并由具有生命周期管理权限的成员执行。目标需同种类、同归属且已发布；引用会迁往保留实体，旧地址可跟随到它，双方的修订历史保留。当前没有撤销合并入口，执行前应确认方向与冲突。

## 修正与争议

修订历史可以帮助核对旧内容；恢复某段资料仍需提交新的修改。已发布条目的下架、合并和停用按管理权限处理。

命名或分类有争议时，在社区关联词条并附来源讨论。恶意破坏或违规内容通过举报处理。进一步的审查清单见[权威编目与审查准则](/curation-guide)。

API 写入的字段、版本和错误码见[新建与编辑](/api-edit)。
