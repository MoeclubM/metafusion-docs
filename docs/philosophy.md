# 核心理念与定位

MetaFusion 希望让作品资料容易查找，也容易核对。社区成员可以共同完善词条，开发者可以用接口复用公开数据。

## 把不同事实放在合适的位置

作品、具体表达与发行版本分开记录。同一份录音被多张唱片收录时，共用录音身份；每张唱片仍保留自己的编号、曲序和包装资料。简单作品只建立有依据的层级，不必凑齐全部结构。

## 让修改有依据

每次修改都写明原因并附参考来源。资料有冲突时说明分歧；无法确认时保留未知。修订记录帮助后续编辑者理解修改，重复条目通过受控合并保留引用。

## 公开查询与受控操作

公开元数据支持匿名浏览与 API 查询。编辑、上传、社区互动及管理操作按账号权限开放，未发布资料按可见性规则保护。

目录记录作品事实，资源模块保存与分发原始文件。文件是否可读取由绑定词条与存储权限决定，贡献者应先确认有权提供相应内容。

## 尊重社区与贡献者

邀请和注册规则由站点设置决定。讨论应围绕可核实事实展开；命名、分类或版权有争议时，通过社区与举报渠道处理。
