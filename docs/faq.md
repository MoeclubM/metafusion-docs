# 常见问题

## 需要注册才能浏览吗？

公开词条和社区讨论可以匿名浏览。互动、编辑与上传需要登录，并受账号权限约束。未发布词条不会公开展示。

## 注册需要邀请码吗？

取决于当前站点设置。登录页会说明是否开放注册，以及是否需要邀请码。需要邀请时，请联系有签发权限的成员或站务。

## 搜索不到就代表没有这个作品吗？

不能据此确定。试试原名、译名、创作者和外部编号，并核对相近候选。搜索结果受关键词、筛选、可见性和索引更新影响；创建前还应确认作品身份。

## 为什么同一名称有多个条目？

它们可能是作品、不同录音或译本、不同发行版，也可能确实重复。先看条目种类、创作者、编号和收录内容。区别见[元数据目录教程](/catalog)，疑似重复时请按[词条编辑与审查规范](/editing-guide)提出合并请求。

## 为什么无法下载文件？

上传者与具有审核权限的人可以直接读取；其他人需要至少一个绑定词条对自己可见。公开词条绑定的文件可匿名读取。访问失败也可能是文件服务暂时不可用，详情见[资源上传与下载](/upload-download)。

## 可以在线播放吗？

平台保存并分发原始文件。下载后用自己的播放器或阅读器打开；当前不提供转码生成的预览流。

## 封面失效怎么办？

先核对图片地址是否仍可访问。封面是图片引用，外部地址可能失效，临时下载地址也会过期。使用有权引用的图片，并为长期保存的文件选择稳定内容入口；编辑要求见[词条编辑与审查规范](/editing-guide)。

## 为什么只能存草稿或提交审核？

账号可能没有直接发布的权限。这时先保存或提交待审，由有权限的成员核对。被退回后按照意见补充来源、修正结构，再重新提交。

## 如何纠正已经发布的资料？

从详情页进入编辑，说明修改依据并提供来源。发现重复条目时先提出合并请求；合并由具有生命周期管理权限的成员处理。历史版本可以用于核对，恢复旧内容仍需提交一次新的修改。

## 可以通过 API 读取和编辑吗？

可以。公开数据支持匿名查询，写入需凭据与相应权限。开发者从[API 概览](/api-overview)开始，Agent 从[AI Agent API 与工具规范](/api-agent)开始。

## 接口限流后怎么办？

按响应中的 `Retry-After` 等待，并减少并发或重复请求。额度随路由、账号与实例策略变化，详见[API 概览](/api-overview)。

## 遇到问题找谁？

一般使用与编目问题可在社区求助；违规内容使用举报入口。Bug 和文档问题的提交方式见[联系方式](/contact)。
